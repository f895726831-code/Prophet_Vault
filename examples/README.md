# Examples

Everything in this folder is generated by:

```bash
python -m prophet_vault demo --out examples
```

The model is **fabricated**. Names, descriptions and formulas come from templates in
`prophet_vault/demo.py`; no number here means anything, and no real model data is included.

## Contents

| Path | What it is |
|---|---|
| `snapshots/demo_2026-01/` | Snapshot of the "previous month" model: 146 variables, four libraries |
| `snapshots/demo_2026-02/` | Snapshot of the "current month" model: 148 variables, with three additions, one removal, one formula change and one description change |
| `diffs/demo_diff.json` | Machine-readable diff between the two snapshots |
| `diffs/demo_diff_report.md` | Human-readable change report |
| `dependency-graph.html` | Single-file dependency-graph viewer - open it in a browser; it loads ECharts from a CDN, or use `--echarts` to inline the library |

`vault/` is deliberately not committed: it is 150+ generated Markdown files. Run the demo to
produce it and open the folder in [Obsidian](https://obsidian.md).

## Things to try

1. Open `dependency-graph.html`, search `NET_CF`, click it, then raise the depth to 2 or 3.
   Click a green upstream chip to walk the dependency chain backwards, and use the back arrow.
2. Read `diffs/demo_diff_report.md` - this is the artefact a reviewer gets after a monthly
   model update.
3. Generate the vault and open `_Index/00-Overview.md` in Obsidian. If you install the
   Dataview plugin, the tables become live queries.
4. Compare the snapshot CSVs: `snapshots/demo_2026-01/formula_hashes.csv` against the same
   file in `demo_2026-02`.

## Regenerating

```bash
python -m prophet_vault demo --out examples          # all outputs, CDN-linked graph
```

For a fully offline graph page, download ECharts once and pass it in:

```bash
curl -L https://cdn.jsdelivr.net/npm/echarts@5.5.1/dist/echarts.min.js -o echarts.min.js
python -m prophet_vault demo --out examples --echarts echarts.min.js
```

The generated data is deterministic for a given `--seed`. Regenerating still touches the
artefacts that carry a timestamp: `created_at` in each `metadata.json`, `generated_at` in
`diffs/demo_diff.json`, `generatedAt` inside the graph HTML, and the date heading in the
vault's `_Index/CHANGELOG.md` (which is not committed).
